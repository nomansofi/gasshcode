Interactive syllabus viewer

Preview the syllabus without leaving this page

The Data Science tab follows the official University of Kashmir 2027 syllabus: 15 units, 4 questions each.

Unit I · Logical ReasoningAnalogies, syllogisms, arrangements, puzzles, Venn diagrams, coding-decoding and number series.
Unit II · English Language and ComprehensionVocabulary, error spotting, idioms, voice, narration and reading comprehension.
Unit III · Sets, Relations and FunctionsTypes and operations of sets, relations, functions, composite and inverse functions.
Unit IV · CalculusLimits, continuity, differentiation, integration and differential equations.
Unit V · Statistics and ProbabilityConditional probability, distributions, data representation and measures of central tendency.
Unit VI · AlgebraQuadratic equations, sequences and series, matrices and determinants.
Unit VII · Computer NetworksNetwork types, topologies, IP addressing basics and internet communication.
Unit VIII · Programming ConceptsAlgorithms, data types, control structures, functions and recursion.
Unit IX · Data Structures and Data HandlingArrays, matrices, searching, bubble sort, stacks and queues.
Unit X · Boolean AlgebraLogic gates, simple circuits and truth tables.
Unit XI · Object-Oriented Programming BasicsOOP principles, C versus C++, and the basic elements and control flow of C++.
Unit XII · Operating System BasicsOS types and functions, 32/64-bit systems, firmware, Windows, Linux, Android and macOS.
Unit XIII · Python Programming BasicsPython features, applications, syntax, variables, data types and operators.
Unit XIV · Computer FundamentalsNumber systems, conversions, binary arithmetic and data representation.
Unit XV · Introduction to Emerging TechnologiesBig data, AI, ML, NLP, AR/VR, robotics, IoT and cloud computing.
Engineering mathematicsLinear algebra, calculus, probability, discrete mathematics.
Core CSDSA, algorithms, OS, DBMS, computer networks, TOC, COA.
Data science trackML foundations, Python, statistics for GATE DA.
Test cadenceWeekly subject tests + monthly full-length GATE mocks.
Python & RSyntax, data frames, visualization, and scripting habits.
C & memory modelPointers, arrays, structs, and debugging discipline.
Data structuresArrays, linked lists, stacks, queues, trees, hashing, graphs.
Mathematics for codingComplexity, combinatorics, and problem-pattern recognition.
